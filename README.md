# Antik Çağ Oyunları

Antik Yunan'da geçen, tarayıcıda çalışan iki küçük oyun. Kurulum gerekmez: HTML dosyasını tarayıcıda açman yeterli.

## 🔥 Meşale Koşusu — `mesale-kosusu.html`

Kutsal ateşi şehre taşırken bronz dev Talos'tan kaçtığın sonsuz koşu oyunu.

| Tuş | Eylem |
| --- | --- |
| ← → / A D | Şerit değiştir |
| ↑ / W / Boşluk | Zıpla |
| ↓ / S | Kay |
| P / Esc | Duraklat |

Telefonda ekranı kaydırarak oynanır. Alçak duvarların üstünden zıpla, kemerlerin altından kay, sütunlardan kaç, uçurumları atla ve drahmi topla.

## 🏛️ Tapınak Muhafızı — `index.html`

Athena Tapınağı'nı barbar dalgalarına karşı koruduğun yukarıdan bakışlı aksiyon/savunma oyunu.

| Tuş | Eylem |
| --- | --- |
| W A S D | Hareket |
| Fare / Sol tık | Mızrak fırlat |
| Boşluk | Atılma |
| Q | Zeus'un Yıldırımı |
| P / Esc | Duraklat |

Dalgalar arasında agorada drahmilerle güçlendirme satın alınır.

## Teknik

Saf HTML, CSS ve JavaScript (Canvas). Hiçbir bağımlılık yoktur.
